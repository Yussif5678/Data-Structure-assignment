# Student Grade Management System

A lightweight, responsive web application built to manage student records and marks using parallel 1D arrays (`names[]` and `marks[]`, maximum 30 students). Created as a high-school computer science assignment.

## Structure
- `index.html`: Main HTML markup.
- `style.css`: Separate CSS stylesheet featuring dark mode, vibrant font colors, and smooth CSS animations (`fadeIn`, `slideUp`, `popIn`, `pulseGlow`).
- `script.js`: Separate JavaScript file handling array logic, validation, search, and sorting.

## GitHub Pages Deployment
1. Create a repository named `student-grade-system`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Enable GitHub Pages in repository settings.
